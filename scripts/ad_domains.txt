# 全局开屏广告域名清单（第三方广告 SDK 专用域名）
#
# 适用：hosts 是全局的，这份清单对手机上所有 App 生效，不再限定某个 App。
# 原则：只收录「广告 SDK / 广告投放平台专用域名」，绝不收录业务接口、账号、
#       推送、支付、图片 CDN 等与正常功能共用的域名。
#
# 格式：一行一个域名，全小写，# 开头为注释，不要写通配符 / 端口 / 路径 / IP。
# hosts 按域名精确匹配，不覆盖子域，所以子域要逐条列出。
# 修改后先本地校验：python scripts/check_ad_domains.py
# 再真机 dry-run：  adb shell su -c "sh /data/local/tmp/adblock_all.sh"
#
# 本清单是「保守集」：宁可漏拦，也不误拦。发现某个 App 还有开屏广告时，
# 用 capture_pcap.sh + pcap_parse.py 抓出它的广告域名，追加到对应分组即可。
